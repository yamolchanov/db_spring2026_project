# SQL Scripts
## Скрипты

| Файл | Описание |
|---|---|
| `top_violators.sql` | Топ нарушителей по общей сумме штрафов |
| `top_articles.sql` | Статистика нарушений по статьям КоАП - какие нарушают чаще всего |
| `expired_license.sql` | Водители с просроченными или аннулированными правами, совершившие нарушения |
| `unpaid_fines.sql` | Неоплаченные штрафы с контактами водителя и госномером автомобиля |
| `officer_activity.sql` | Количество нарушений, зафиксированных каждым инспектором |
| `violations_by_city.sql` | Нарушения и суммы штрафов по городам |
| `vehicle_violation_story.sql` | История нарушений по каждому автомобилю |
| `disputed_fines.sql` | Оспариваемые штрафы с деталями по нарушителю и инспектору |
| `fines_by_month.sql` | Динамика количества и суммы штрафов по месяцам |
| `dep_summary.sql` | Сводка по отделам ГИБДД: инспекторы, нарушения, сборы |

## Запуск

```bash
psql -U <имя_пользователя> -d traffic_violations -f base_part/scripts/<имя_файла>.sql
```
